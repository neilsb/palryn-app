# Palryn

**A desktop MongoDB client for Windows and Linux.**

Palryn helps you explore databases, query and edit documents, build aggregation
pipelines, and organise your work across multiple connections.

This repository is the public home for **bug reports, feature requests and
community conversations** about Palryn.

- [Website](https://palryn.app/)
- [User documentation](https://docs.palryn.app/)

- [Questions and discussions](https://github.com/neilsb/palryn-app/discussions)

## Report a bug

Something not working as expected?
[Open an issue](https://github.com/neilsb/palryn-app/issues/new/choose)
and describe what happened.

A useful bug report includes:

- Your Palryn version.
- Your operating system and version.
- Steps to reproduce the problem.
- What you expected to happen and what actually happened.
- Any relevant error messages or screenshots.
- Your MongoDB server version, if relevant.

Please search existing issues first. If someone has already reported the same
problem, add any extra details to their report.

**Before posting, remove passwords, connection strings containing credentials,
and private data from screenshots, logs and examples.**

## Suggest a feature

Have an idea for making Palryn better?
[Open a feature request](https://github.com/neilsb/palryn-app/issues/new/choose).

Tell us:

- What you’re trying to achieve.
- What currently makes that difficult.
- How you’d like Palryn to help.

Real-world examples are especially useful. If a similar request already exists,
add a 👍 reaction or a comment explaining your use case.

For ideas you’d like to explore before making a specific request, start a
[discussion](https://github.com/neilsb/palryn-app/discussions).

## Ask a question or join the conversation

Use [Discussions](https://github.com/neilsb/palryn-app/discussions) to:

- Ask questions about using Palryn.
- Share tips and workflows.
- Discuss ideas and possible improvements.
- Share general feedback.

The [user documentation](https://docs.palryn.app/) is a good starting point
for setup instructions and feature guides.

## Taking part

You don’t need to contribute code to help improve Palryn. Clear bug reports,
thoughtful suggestions and feedback on existing issues are all valuable.

Please keep conversations friendly, constructive and focused. Feature requests
help inform development, but aren’t a commitment to a particular release or
delivery date.

Thanks for helping shape Palryn.
